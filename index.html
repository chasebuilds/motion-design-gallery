How these are built

  • Reduced motion. Every piece checks prefers-reduced-motion and shows the finished state without moving.
  • Cheap to animate. Pieces animate transform and opacity only, so the browser can run them off the main thread.
  • Self-contained. Each demo runs in a sandboxed frame. The code view shows the exact file that is running.
